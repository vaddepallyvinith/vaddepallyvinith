## 🚀 Featured Projects

### 1. Ontology-Guided Semantic Alignment for ESG Disclosures

**Technologies:** Python · RDF/OWL · SKOS · SPARQL · Sentence Transformers · LangGraph · NetworkX

- Developed a five-phase ontology framework to align SEBI BRSR environmental disclosures with GRI standards.
- Structured a knowledge base covering **755+ disclosures and 312+ metrics across 42 GRI standards**.
- Built a hybrid semantic mapping approach combining graph analysis, embeddings, and LLM-based evaluation.

🔗 [View Project](https://github.com/vaddepallyvinith/ESG_XBRL_P_V_IITH/tree/main/EXTENSION_2)

### 2. Shipment-Sure — Shipment Delay Prediction

**Technologies:** Python · Flask · XGBoost · Scikit-learn

- Developed a machine-learning system to predict shipment delays.
- Engineered **90+ features** and investigated factors associated with delivery performance.
- Built a Flask API to make model predictions accessible to applications.

🔗 [View Project](https://github.com/vaddepallyvinith/Shipment-Sure/tree/main)

### 3. YONO SCIS — Distributed Banking Application

**Technologies:** Python · TCP Sockets · SQLite · Multithreading

- Built a distributed banking application inspired by digital banking workflows.
- Implemented fund transfers, role-based access control, and distributed service concepts.
- Explored load balancing, Two-Phase Commit, and fault-tolerance mechanisms.

### 4. Predictive Cache Management with Neural Networks

**Technologies:** C · C++ · Python · Machine Learning

- Exploring neural-network-based prediction of future memory accesses.
- Evaluating predictive cache management against traditional prefetching approaches.
- Studying cache hit rates, Instructions Per Cycle (IPC), and inference overhead.

### 5. Generative AI Conversational Assistant Applications

**Focus:** Generative AI · Conversational Systems

- Worked on developing Generative AI applications for conversational assistant use cases.
- Completed a three-month internship and documented findings in a case study.
